## 产品思考

用的人是发电企业的交易员，例如三峡广东蕴阳海风场的张敏。她懂日前、实际、披露、日清算、月结算单和运行日报，不懂 YAML、重试次数和 `D-1`。软件装在值守的 Windows 电脑上，证书插在这台机器上，文件落到本机目录，也可以再上传。

她真正要回答的只有一句：**数据到位了没有。** 配置任务是安装时和偶尔调整时的事，不是每天打开软件的理由。

五个场景：

1. **早间巡检。** 上班先看昨天该到的数齐了没有。齐了就走。缺了要能指出是哪一天、哪一项，并马上补。
2. **采集被拦住。** 交易中心要验证码，或工作台弹出公告。人要知道现在停在哪、自己该做什么、做完怎么让同一次采集继续。不要因此去改计划。
3. **更早的洞。** 周末没人看，某一天漏了。这和「今天这次没跑完」不是一件事，要从格子上单独补。
4. **第一次安装。** 证书、场站、要的数据、保存位置。能识别的就先填好，让她确认，而不是交一张空表。
5. **月初。** 月结算单到了取单窗口才出现缺口。没到窗口是正常，不要画成故障。

据此，信息架构倒过来：

- 一级是 **到位**。按数据类型 × 业务日期看齐没齐。
- **补采** 从缺的格子进去，不是一套和定时任务平行的向导。
- **计划** 降到二级，只回答「什么时候自己跑、跑哪些、写到哪」。
- **记录** 留给事后对文件，不占首页。
- 设置里的证书、上传、重试，不出现在每天的路径上。

日期用业务日，不用 `D` `M`。日前交易结果在前一晚发布，所以 11月13日早上，11月13日的日前应该已经在；实际、披露、日清算、运行日报要到次日早上才有，所以 11月13日这四项是「还没到发布时间」，不是缺失。11月结算单要到 12月上旬，10月的单已经在 11月3日入库。

## 这一天的故事

示例把四个场景收在同一个早晨，避免每张图各讲各的。

08:00 开始自动采集。08:03 写入了 11月13日的日前、11月12日的信息披露和运行日报。08:06 交易中心要求验证码，实际运行结果和日清算没采成。所以昨天的缺口是这次被拦住，不是计划没开。另外 11月7日的日清算、11月8日的实际运行结果是更早的洞，要单独补。

首页因此不会写「昨日 7 项已全部到位」。那句话留给格子全绿的早晨，句式相同，只是结论变了。有缺口的早晨更值得被设计，因为这是她要做决定的时候。

## 关键流程

见 [flow.png](images/flow.png)。

每天早上：打开 → 看一句话 → 齐了就离开；没齐就分清是「这次被拦住」还是「更早的洞」。

被拦住：看右侧页面。是验证码就填上继续；是公告就只点「关闭」或「我知道了」，不要点「去签署」「确认」「同意」。继续的是同一次采集，不改 08:00 的计划。回到看板，11月12日那两格变绿。

更早的洞：点琥珀色格子 → 确认文件和位置 → 若登录还停着，先去填验证码 → 再开始补采。

第一次使用：确认登录、场站、数据、位置，然后进入看板。月初：月结算单那一格到了窗口，走同一条补采。

## 视觉

规范见 [visual-spec.png](images/visual-spec.png)。语气对齐国网、南网新一代业务系统：海军蓝打底，细金线只作标记，白卡片，状态靠颜色而不是说明段落。

| 角色 | 色 | 用在 |
| --- | --- | --- |
| 行动 | `#0E5CAD` | 一屏一个主按钮 |
| 品牌底 | `#0C2340` | 侧栏、标题 |
| 金线 | `#B8904E` | 标题下 36px 的一根线，不用大面积金 |
| 画布 | `#E7EEF4` | 页面底 |
| 到位 | `#0D7A46` | 已入库 |
| 可补 | `#C05621` | 缺了、可以点 |
| 要人处理 | `#B42318` | 验证码、暂停 |
| 次要文字 | `#6B7D8D` | 辅助 |

字体只四级：结论 28–32 / 700，区块 15–18 / 600，正文 14 / 400，辅助 12 / 500。数字用等宽数字。按钮圆角 8，卡片 14，阴影一层。图标是 18px、线宽 1.75 的线性图标。间距用 8、12、16、20、24。

到位、可补、未出是三种不同的格子，不能都画成灰色说明。可补格子里写「补」，因为这就是动作。

### 补采

[catchup.png](images/catchup.png)

从 11月12日的日清算格子进来。同一天的实际运行结果也缺，默认一起勾上。文件名、大约体积、上次成功日期、写入路径都在决定之前给她看。已经在库里的信息披露和运行日报明确写成「不用再下」。

右侧先说这一步的顺序：现在补也会撞上同一个验证码，所以主按钮仍是去填写验证码，次按钮才是「我已登录，开始补采」。补完后那两格会变成勾。11月7日、11月8日这次不动。

### 需要你处理

[attention.png](images/attention.png)

左边三步：看右侧验证码，填在这里，回到看板看 11月12日。输入框不预填答案。右边是采集浏览器停在 `pm.gd.csg.cn` 登录页的样子，证书已识别为三峡新能源阳江发电有限公司。

若右边不是验证码而是公告，同一页底部写清：只点「关闭」或「我知道了」，不要点「去签署」「确认」「同意」。这句留下来，因为它防止点错，不是用法说明书。

### 采集计划

[plan.png](images/plan.png)

计划是二级。页头写明：计划只决定自动跑的时间和范围，每天早上先看到位看板。

每日采集开着，七项都用结果描述，不用偏移量。明天 08:00 将采 11月14日的日前，以及 11月13日的实际、披露、日清算、运行日报。交易日历每月 1 日核对当月，月结算单每月 3 日起取上月。下面直接列出明天会写下的五个文件名，以及目录 `D:\电力交易数据\蕴阳海风场\2026-11\13\`。失败再试收成页脚一行。

## 和上一版的差别

上一版把现有表单换成「采什么 / 什么时候 / 存到哪」，仍是任务配置软件，只是说明少了。这一版把每天的第一屏改成到位情况。计划、路径、重试都从第一屏拿掉。缺数、验证码、首次安装、月初结算单用同一套格子和同一套颜色讲完。
