## 5. 采集与运行口径

1. **以页面自动化为主路径**：接口方式在已确认并完成联调的指标上启用，不承诺所有指标同时支持页面与接口两种方式。
2. **人工保底**：证书、验证码、页面异常等无法自动处理的场景，暂停当前整次任务并提示人工处理，不静默跳过、不误报完成。
3. **暂停与恢复粒度**：暂停作用于"当前整次任务"，人工确认后恢复或整体重跑；不承诺任意步骤的无损续跑。
4. **重试边界**：登录与验证码自动重试次数有限，避免 U-Key / PIN 被连续错误提交；失败即停止自动重试并告警。
5. **数据落地优先**：网络或交付通道不可用时，已有采集结果仍保留在本机并可查询。
6. **不做的承诺**：不承诺未经本项目实测的采集成功率、人工节省比例与连续无故障运行时长。

## 6. 数据流向、外发范围与安全合规

### 6.1 数据流向

```
交易平台 ──(专网 / U-Key)──▶ 采集工作站（本机落地：原始结果 / 台账 / 压缩包）
                                        │
                                        └─▶ 客户内网（共享目录或接收接口，按客户指定通道）
```

采集数据落在客户工作站本机；交付给客户内网的方式由客户指定。**不引入第三方云端存储**。

### 6.2 对外发送的内容范围

| 类别 | 内容 | 用途 |
| --- | --- | --- |
| 告警通知 | 任务名、时间、失败原因摘要 | 通知客户指定接收人 |
| 执行日志 / 诊断包 | 执行日志、应用日志（最近 500 行）、**脱敏后的**配置摘要、健康检查、网络诊断 | 远程排查问题 |

- 发送通道：钉钉 / 企业微信 / Server酱等，**按客户选择**；接收人由客户指定。
- 若客户环境不允许任何外发通道，可关闭通知与上传，改为纯本机留痕。
- 诊断包中的配置摘要需脱敏后生成，不包含账号密码与证书 PIN；**具体脱敏字段清单在试点前与客户确认**。

### 6.3 凭据与 U-Key 管理

- 账号密码、证书 PIN 保存在工作站本机配置中，仅采集程序读取；如需接入客户密码管理系统或加密存储改造，另行确认。
- U-Key 由客户保管与领用登记；采集程序仅在执行期间访问，不复制证书文件。
- 账号建议专用（不与人工共用），人员变动时及时回收与变更。

### 6.4 操作留痕

任务与步骤日志、失败现场截图、文件版本记录（内容摘要）保留在本机，作为问题定位与验收依据；保留周期【待确认】。

## 7. 实施阶段、里程碑与退出标准

| 阶段 | 主要活动 | 退出标准（双方确认后进入下一阶段） |
| --- | --- | --- |
| 一、单链路试点 | 现场环境确认；1 个交易单元、首批代表性指标接入；账号 / U-Key / 专网联调 | 登录成功；采集文件与业务口径核对一致；异常能暂停并告警；失败可定位 |
| 二、日常运行 | 定时执行与补数窗口；异常处理流程固化；告警接收人确定 | 正常能跑、失败能停；连续观察期内的执行记录可追溯（观察周期【待确认】） |
| 三、扩展交付 | 内网接收通道对接；按业务优先级增加指标；按需增加交易单元 / U-Key（单独验证） | 接收文件可核对、归属清晰；新增指标逐个验收通过 |

- 每阶段开始时确认当期指标清单、采集频次、异常处理方式与验收样本。
- 多 U-Key 轮转、跨单元并发按独立原型验证，不与上述三期进度捆绑。

## 8. 验收方式

1. **按指标验收**：以具体账号权限、指标、业务日期范围、产出文件为验收对象。
2. **验收样本**：由客户指定日期与指标的期望结果，与工作站产出逐项比对。
3. **异常路径验收**：断网、证书 / PIN 异常、验证码失败、导出失败等场景下能暂停并告警、留证可查。
4. **交付通道验收**：客户内网接收端可核对文件内容与归属，异常时有明确处理入口。
5. 不通过的情形：静默跳过失败、误报完成、文件内容与业务口径不一致。

## 11. 术语

| 术语 | 含义 |

| 留证 | 失败现场截图、执行日志与诊断包 |
