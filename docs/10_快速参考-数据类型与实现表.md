### 数据示例

```

时刻    | 电量(MWh) | 开机台数(台)
--------|-----------|------------
0:00    | 71875.08  | 265
1:00    | 68858.98  | 253
2:00    | 64360.61  | 243
...
23:00   | 92340.55  | 380
```

### 生成规则

- **基础电量**: 80000 MWh
- **波动幅度**: ±30%（谷值50k, 峰值120k）
- **开机台数**: 250 + (电量-50000)/1000（与电量正相关）
- **时间跨度**: 24小时（00:00-23:00）

### 代码骨架

```python
@app.get("/api/spot_clearance/{trade_type}")
async def get_spot_clearance(trade_type: str = "real") -> list[dict]:
    """
    trade_type: 'real' 或 'day_ahead'
    """
    return _generate_spot_clearance_data(trade_type)

def _generate_spot_clearance_data(trade_type: str) -> list[dict]:
    data = []
    base_energy = 80000 if trade_type == "real" else 75000
    for hour in range(24):
        variance = random.uniform(-0.3, 0.3)
        energy = base_energy * (1 + variance)
        units = int(250 + (energy - 50000) / 1000)
        data.append({
            "时刻": f"{hour}:00",
            "电量(MWh)": round(energy, 2),
            "开机台数(台)": units
        })
    return data
```

## 市场用电信息 Mock 实现

### 数据示例

```
工作表: 首页负荷信息市场用电数据

类型              | 00:00       | 01:00       | 02:00       | ... | 23:00
-----------------|-------------|-------------|-------------|-----|----------
市场用电需求(MWh) | 120449.23   | 112434.50   | 103256.92   | ... | 103017.68
市场实际用电(MWh) | 104409.34   | 99468.77    | 95521.66    | ... | 99014.14
```

### 生成规则

- **基础需求**: 100000 MWh
- **日间系数**: 10-12点/17-19点 = 1.15x（峰值）, 2-5点 = 0.85x（谷值）
- **需求-实际 Gap**: 实际通常低于需求 10-15%
- **时间粒度**: 1小时（00:00-23:00共24个点）

### 代码骨架

```python
def _generate_market_electricity_data() -> dict:
    base_demand = 100000
    demand = []
    actual = []
    
    for hour in range(24):
        # 日间系数
        if hour in (10, 11, 17, 18, 19):
            coeff = 1.15  # 峰值
        elif hour in (2, 3, 4):
            coeff = 0.85  # 谷值
        else:
            coeff = 1.0
        
        hour_demand = base_demand * coeff * random.uniform(0.95, 1.05)
        hour_actual = hour_demand * random.uniform(0.87, 0.93)
        
        demand.append(round(hour_demand, 4))
        actual.append(round(hour_actual, 4))
    
    return {
        "需求": demand,
        "实际": actual,
        "时间": [f"{h}:00" for h in range(24)]
    }
```

## 日前节点电价 Mock 实现（简化版）

### 数据示例

```
工作表: 日前节点电价查询

节点名称              | 数据项      | 00:00 | 00:15 | ... | 23:45
---------------------|-----------|-------|-------|-----|-------
其他500kV水城变#1M   | 电价元/MWh | 356.75| 597.43| ... | 342
其他一总降站220_KV#1 | 电价元/MWh | 359.81| 581.98| ... | 342.99
[共50个节点...]
```

### 生成规则

- **节点数**: 简化为50个代表节点（真实2838个）
- **基础电价**: 350-450 元/MWh（随机）
- **时间粒度**: 15分钟（96个时间点）
- **峰值系数**: 11-14点/18-21点 = 1.2x
- **异常值**: -50元/MWh（凌晨00-03时出现，频率5-10%）
- **波动范围**: 相邻点间 ±50-100 元/MWh

### 代码骨架

```python
SAMPLE_NODES = [
    "其他500kV水城变500kV#1M",
    "其他一总降站220_KV#1",
    "其他一总降站220_KV#2",
    # ... 共50个
]

def _generate_node_prices_simplified(num_nodes: int = 50) -> list[dict]:
    data = []
    for node in SAMPLE_NODES[:num_nodes]:
        prices = []
        base = random.uniform(350, 450)
        
        for i in range(96):  # 96个15分钟
            hour = i // 4
            
            if i < 12:  # 凌晨00-03点
                price = -50 if random.random() < 0.1 else base
            else:
                if hour in (11, 12, 13, 18, 19, 20):
                    coeff = 1.2  # 峰值
                else:
                    coeff = 1.0
                price = base * coeff + random.uniform(-50, 50)
            
            prices.append(round(price, 2))
        
        data.append({
            "节点名称": node,
            "电价(元/MWh)": prices
        })
    
    return data
```
