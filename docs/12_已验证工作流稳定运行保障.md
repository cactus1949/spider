# 已验证工作流稳定运行保障

范围：`参考/workflows_export_已验证单个运行通过` 下的 5 个 YAML。

## 当前保障

- 登录错误弹窗：`dismiss_modal(report_error=true)` 会触发 `error_pause`，发送告警，并阻断 `workflow_done/task_done`。
- 站点不可达：`Page.goto` 的 `net::ERR_CONNECTION_CLOSED/REFUSED/RESET/NAME_NOT_RESOLVED/INTERNET_DISCONNECTED/TIMED_OUT` 等会触发 `site_unreachable`，用于识别随身 WiFi/专网断开，并附带随身 WiFi、专网路由、DNS、代理等诊断建议。
- 任务状态：工作流失败会向 `TaskRunner` 传播，任务不会再显示完成。
- 定时任务：`site_unreachable`、`captcha_failed`、`error_pause`、`step_error`、`task_error` 都会写入失败原因。
- 前端进度弹窗：`site_unreachable`、`captcha_failed` 和 `error_pause` 都会把当前运行步骤标红，不再显示完成。
- Datepicker：Element UI / Element Plus 日期选择优先使用“年份 -> 月份 -> 日期”的面板路径，远日期如 `2025-01-01` 不再依赖连续点击十几次上月箭头。
- 登录成功检测：验证码提交后逐个检查 `.el-menu`、`.el-submenu`、`text=现货交易`、`text=工作台`，避免把 CSS 与 Playwright `text=` 引擎混写成非法选择器。
- 半登录识别：额外要求 `require_storage_keys`（`登陆流程测试.yml` 用 `pfxh-token`）已落盘；只有工作台元素、没有 token 时判为半登录，刷新一次自愈，仍失败则 `error_pause` 并提示 `reset_site_storage`。
- 登录失败提示：除 `.ant-modal-confirm` 外也读 `.el-message-box`、`.ant-message-error`、`.el-message--error` 等 toast；暂停原因带控制台/页面异常摘要。
- 登录提交后的认证请求若返回 4xx/5xx，会立即触发 `error_pause`，不会继续执行后续导航或导出步骤；登录前的 `logged/info` 未登录探测仍可继续表单。
- 站点残留清理：`reset_site_storage` 按 origin 清 local/session/cookie（CDP 清 httpOnly），对应现场“清空存储后恢复正常”的人工步骤。
- 网关拒绝自愈：同源业务 XHR 返回 4xx/5xx 时自动重建文档（关掉新开标签页回到根页面，或刷新当前文档），并从最近一次 `expect: new_tab` 的点击步骤回放；事件 `page_recovery` / `page_recovery_done`，`page_recovery: off` 可关闭。
- 数据查询等待：`pick_date` 选完日期后等网络静默，`click expect: new_tab` 等新文档初始化请求跑完，避免数据未回来就导出。
- 失败诊断：失败时把 URL、标题、localStorage 键名、`runDay`、4xx 记录、控制台与页面异常写到 `_failures/diagnostics_<时间>.log`。
- 导出失败：`export` 捕获不到下载会先尝试工作流级 `api_fallback`；fallback 成功则保存文件并继续，fallback 不存在或失败才抛出工作流错误，阻断 `workflow_done/task_done`。
- 导出前等待：不再只依赖配置里的固定等待毫秒数；导出会等待当前业务页的查询请求完成，成功后默认再稳定 1.2 秒。`query_wait_timeout` 和 `query_settle_ms` 可按步骤覆盖；请求失败或超时仍会告警并暂停。
- 下载路径：`save_as: /业务子目录/file.xlsx` 会落在下载目录下，只有存在真实父级的路径才按系统绝对路径处理。
- 验证码失败留证：验证码识别耗尽或登录重试耗尽会触发 `captcha_failed`，保存 `_failures/*.png` 现场截图；无人工继续信号时直接失败，不会静默完成。
- Mocksite：新增 `/portal/`、`/pfxh/stc/check`、`/pfjs/stc/check` 工作流 mock 页面，保留参考 YAML 依赖的 Element UI 类名与关键 DOM：
  - `.el-submenu__title`
  - `.el-menu-item`
  - `.style-box-head`
  - `.dateBox .el-input__inner`
  - `.exportBtnColor`
  - `.headBtn`
  - `.head-item`
  - `.elx-table--body`
  - `.el-date-picker__header-label`
  - `.el-year-table`
  - `.el-month-table`
