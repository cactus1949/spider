# 运行日报下载工作流（纯页面操作）

文件：`workflows/运行日报.yml`。

## 业务流程

登录后进入门户首页 → hover 资讯公告 → 点击市场运行报告 → 在列表里找到
目标日期的报告 → 点击标题进入详情 → 点击详情页附件“下 载”。

全程使用真实页面：

- `navigate` 打开门户首页；
- `hover` 资讯公告；
- `click` 市场运行报告；
- `download_notice_reports_ui` 在列表页真实点击、真实翻页、真实点附件下载；
- 不调用列表接口，不抓接口数据。

## 日期窗口

- 动作本身一次只处理一个 `target_date`，不循环日期。
- 任务配置 D-3~D 时，任务执行器按天逐日运行这个指标（replay 模式），
  每天跑一次，每次 `target_date` 是一天。
- 单独手动执行、没有任务窗口时，`target_date` 是运行当天。
- 标题日期优先于发布时间，例如
  `广东电力现货市场2026年10月运行日报（10.27）` 匹配 2026-10-27。

## 下载方式

- 不打包 ZIP。
- 每个报告、每个附件单独点击下载，文件名使用浏览器下载的附件原名。
- 同一天多份报告/多个附件全部下载。

## 动作配置

```yaml
- action: download_notice_reports_ui
  list_selector: ".ant-list-item"
  title_selector: ".itemTitle, .itemTitleReceipt"
  time_selector: ".itemTime"
  next_selector: ".ant-pagination-next"
  download_selector: ".attachments button"
  max_pages: 10
  save_as: 日报附件
```

- `save_as` 只是存储结构里的标签名，不是实际文件名。
- 列表项、标题、发布时间、下一页、详情附件按钮都可以按实际页面改选择器。

## 分页和返回

- 每处理完一个报告，重新打开列表 URL，再点“下一页”回到当前页；避免
  SPA 从详情返回后分页状态丢失。
- 目标日期的报告通常在前几页；`max_pages` 限制最多扫多少页。
- 同一天多份报告会逐个处理；已处理标题会跳过。

## 存储结构

工作流产物清单里会多一个 `日报附件` 标签（输出 key 是步骤索引 `s6`）。
在“存储结构”里把它拖到目标文件夹即可，所有附件都会进这个目录。
