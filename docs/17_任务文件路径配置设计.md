# 任务存储结构：标签式低代码编辑器

状态：2026-10-30 按“标签 + 拖拽 + 树”重做。左边是可用标签，右边是结构树，
标签可以拖进树里、在树里拖动换位置；每个文件标签都标了来自哪个指标。

## 1. 效果

```text
┌─ 存储结构 ──────────────────────────────────────────────────────┐
│ 根目录  D:\交付\现货组\（设置里改）                               │
│                                                                 │
│ 可用标签              │  结构（拖标签进来）                       │
│ 位置                  │  下载根目录                               │
│ [WiFi 名称]           │  └─ [WiFi 名称] CSG-UKEY                  │
│ [{YYYY}]              │     ├─ [现货分时分类型出清电量日前.xlsx]   │
│ [{YYYY-MM}]           │     │    来自：现货交易-完整采集           │
│ [{YYYY-MM-DD}]        │     ├─ [现货分时分类型出清电量实时.xlsx]   │
│ 文件夹                │     │    来自：现货交易-完整采集           │
│ [新文件夹]            │     └─ 披露文件                          │
│ 文件                  │        ├─ [市场用电信息(2026-10-29).xlsx]│
│ 现货交易-完整采集      │        │    来自：现货交易-完整采集        │
│  [市场用电信息...]     │        └─ 交易日历2026-10.csv            │
│  [出清电量日前...]     │             来自：交易日历                │
│  [出清电量实时...]     │                                          │
│  [信息披露预测...]     │                                          │
│  [信息披露实际...]     │                                          │
│ 交易日历              │                                          │
│  [交易日历2026-10.csv] │                                          │
│                                                                 │
│ 预览：D:\交付\现货组\CSG-UKEY\披露文件\...                       │
└─────────────────────────────────────────────────────────────────┘
```

- **一个指标有几个 export/extract，就显示几个文件标签**。例如
  “现货交易-完整采集(含披露中心)”会展开 5 个标签。
- 文件标签直接写成 **`指标名：[子目录] save_as 文件名`**，例如
  `日前节点电价查询导出：日前节点电价查询(D-1).xlsx`。如果任务配置了
  D-2 到 D，就显示 `市场用电信息(D-2~D).xlsx`，不写具体日期。
- 同一个 save_as 文件名但子目录不同的（例如 `日前` / `实时`），标签会带
  `[日前]` / `[实时]`，不会看起来像重复。
- 文件标签是**叶子**；WiFi、日期、文件夹是容器，可以把文件标签拖进去。
- 标签可以拖：调色板 → 结构树，结构树内换文件夹，拖回根目录。
- **新建文件夹更方便**：根目录、WiFi、日期、每个文件夹右侧都有 `+ 文件夹`，
  点一下就在它下面建子文件夹，并自动进入改名状态；调色板的“新文件夹”拖进来
  也会自动进入改名。
- 双击文件夹改名；`×` 删除。
- 悬停 WiFi/日期标签会提示：`{wifi}` 会换成当前 WiFi，`{YYYY-MM-DD}`
  会换成执行日期。

## 2. 标签说明

| 标签 | 作用 |
| --- | --- |
| WiFi 名称 | 动态目录，执行时换成当前连接的 SSID；可以删掉，完全自定义 |
| `{YYYY}` / `{YYYY-MM}` / `{YYYY-MM-DD}` | 日期目录，按任务执行日展开 |
| 新文件夹 | 静态文件夹；可嵌套；双击改名 |
| 文件标签 | 某个指标的具体 export/extract 产物；标签上显示文件名，旁边标来源指标 |

- WiFi 和日期都可以不用；不用 WiFi 就是纯自定义结构。
- 日期标签可以放在任意层级。
- 文件夹名不能含 `[ ] { } / \`；文件夹嵌套用拖拽，不靠斜杠。

## 3. 存储结构格式（后端实际读的）

编辑器保存成缩进结构，例如：

```text
- {wifi}
  - 披露文件
    - [现货交易-完整采集(含披露中心)::s6]
    - [交易日历::s7]
  - 按日期
    - {YYYY-MM-DD}
      - [现货交易-完整采集(含披露中心)::s10]
```

- `[指标::输出key]` 表示一个具体文件；输出 key 是工作流步骤索引（`s6`）。
- 旧结构里的 `[指标]` 会自动展开成该指标的所有输出。
- 服务端按 key 找到对应 export/extract 步骤，把文件落到该标签所在目录；
  同一指标的不同文件可以放在不同文件夹。
- 文件名仍然不配置：导出类用系统原名/工作流 `save_as`，识别类用 `save_as`。

## 4. 后端

- `/api/workflows` 增加 `outputs`：每个指标的 export/extract 步骤清单
  （key/label/save_as/action/step_index）。
- `path_structure` 保存缩进结构；`PathStructure` 解析后得到
  `指标::输出key → 文件夹层级`。
- 任务执行：
  - 解析结构，得到每个输出的目录和共同基础目录；
  - `TaskRunner` 把 `指标 → {输出key: 目录}` 传给 `WorkflowRunner`；
  - `WorkflowRunner` 在执行第 i 步时使用 `s{i}` 对应的目录；
  - 导出/提取/交易日历都走这套目录。
- 根目录仍来自设置里的下载目录；当前 WiFi 自动解析。
- 标签里的 `D-2~D` 来自任务里该指标的日期窗口；月份指标显示 `M-1` 这种。
- 如果界面上还显示“系统文件名”，说明运行中的后端没有返回 `outputs`
  （旧后端），重启/重新构建后端后就会按 save_as 显示；一个指标有几个
  save_as 就会有几个标签。
- 旧任务没有 `path_structure` 时，用旧的 `path_template + path_folders` 自动生成
  初始结构，不会丢原来的目录。

## 5. 限制

- WiFi 节点是动态的一个；同一任务在不同 WiFi 下用同一套结构。
- 输出 key 跟工作流步骤索引绑定；工作流大改后，旧结构里的 key 可能失效，
  预览会报错，重新拖一下标签即可。
- 只按执行日期，不按数据日期。
- 一个文件标签对应一个步骤；步骤内部再拆多文件的情况仍算一个标签。
