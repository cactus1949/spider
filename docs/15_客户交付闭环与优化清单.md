# 客户交付闭环与优化清单

## 交付页面分层

当前交付版本默认展示全部保留页面：

- 首页：日历视图查看每天计划任务、成功/失败/运行中状态和运行进度，点击日期查看当天详情，点击任务查看步骤日志。
- 文件中心：查看下载数据、打开目录、压缩文件。
- 任务配置：配置日常任务、启停定时、立即执行、可见运行。
- 执行日志：查看失败原因、下载日志、一键上传日志。
- 指标配置：编辑工作流 YAML、录制/回放单个指标。
- 录制工坊：录制新工作流、导出 ZIP、提交原始录制包。

助手页面已移除。当前更适合客户/实施共同使用，所有业务页面都可以直接从侧边栏进入。

## 已补齐闭环

- 登录熔断：敏感变量未替换、证书/PIN 弹窗、登录后不进工作台时立即暂停并终止本次自动重试，避免 UKey/PIN 被连续错误提交。
- 定时任务凭证：定时任务会读取前端设置中的 `certPassword/account/accountPassword`，兜底读取后端 `CRAWLER__...` 配置。
- 执行日志上传：执行日志页支持一键上传，上传地址和 Token 复用录制工坊设置，远程路径为 `/upload/publicData/logs`。
- 日期选择验证：mocksite 新增 `element-ui`、`element-plus`、`antd` 日期选择实验页，Playwright 集成测试验证指定日期可被选中。
- 文件版本策略：核心数据落地、RPA 下载导出、WorkflowRunner 表格/接口/ECharts/JSON 等数据输出按 SHA256 判断内容。内容相同不覆盖；内容变化时原路径保存新文件，旧文件归档到同目录 `_versions`。
- 文件版本可视化：文件中心支持查看当前文件 SHA256、manifest 记录、历史版本文件、归档时间和大小。
- 任务向前/向后窗口：任务执行会展开目标日期。默认 `向前 1 天 / 向后 0 天` 只跑昨天；向前 N 天按从早到晚补数，向后 M 天从今天开始覆盖 M 天。目标日期会同时影响 `pick_date` 和 `{date}` 保存文件名。
- 首页日历驾驶舱：左侧大日历展示当天定时任务和执行结果，成功/失败用底色区分，运行中以进度条背景显示；右侧展示选中日期详情，任务抽屉持续刷新运行中步骤。
- 诊断包上传：执行日志页支持一键上传诊断包，包含执行日志、`app.log` 最近 500 行、脱敏配置摘要、健康检查和网络诊断，远程路径为 `/upload/publicData/diagnostics`。
- 统一通知通道：异常告警以“结果发送”为唯一运行时来源；任务失败、登录失败、网络异常会走同一个 webhook/Server酱/PushPlus 出口，旧 `alert.*` / `alertChannelsJson` 配置不再参与路由。发送失败会写入本地 `alert_outbox.jsonl`，调度器每 5 分钟主动尝试补发，后续告警触发时也会顺带补发。
- 隐藏运行策略：控制接口收到 `headless=true` 或 `minimized=true` 时，统一切换为离屏可见 Chrome，并禁用后台窗口限速，避免 UKey/目标站点在真 headless 下出现登录按钮、步骤元素等待不到的问题。
- 隐藏运行稳定性：不可见运行不再使用 Chrome 最小化参数，改为离屏窗口并禁用后台节流，减少最小化渲染差异导致的元素找不到。

## 仍需优化

- 文件版本恢复/对比：当前能看到版本信息和打开历史文件；如果客户要“一键恢复旧版本”或 Excel 差异对比，需要再做操作入口。

## 客户确认项

- 任务向前/向后窗口是否按自然日即可，还是要改为交易日/工作日，并接入节假日表。
- 补数遇到同 hash 文件时是否完全跳过上传/发送，还是仍记录“已确认未变化”。
- 文件发生变化时，客户希望默认打开最新文件，还是在文件名中显式带版本号。
- 日志上传目标路径是否固定 `/upload/publicData/logs`，或按客户/项目/日期分层。
